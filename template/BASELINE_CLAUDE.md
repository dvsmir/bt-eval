# Project notes

This is a Gradle project. It uses the Kotlin DSL.

- Build it and run its tasks with the Gradle wrapper: `./gradlew <task>`.
- You may run any Gradle task you need, and you may read any file in the project.
- `JAVA_HOME` is already set for you. Do not change it.
- Add `--console=plain` when you want output that is easy to read.
- Work only inside this directory.
